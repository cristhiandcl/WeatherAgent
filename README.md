## **`Weather AI Agent`**

An AI agent that can tell you the current weather of any location

## **`how to start`**

All you need to run this project once cloned is to provied your **OPENAI_API_KEY** and **WEATHER_API_KEY** in a .env file you must create inside the backend folder, once
that's done, simply run `docker-compose up --build` and start talking with the agent on **http://127.0.0.1:3000/**
